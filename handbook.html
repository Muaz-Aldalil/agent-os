FRONTEND & CMS SHELL ARMOR

                
Sticky Layout, Tables, Forms & RTL

                
    
                  
  • Sticky Top Navbar: sticky top-0 z-30 stays pinned on scroll.
    • 
                  
  • Sticky Desktop Sidebar: lg:sticky lg:top-0 lg:h-dvh lg:overflow-y-auto + mobile off-canvas drawer on <1024px.
    • 
                  
  • Main Column Overflow Lock: flex-1 min-w-0 prevents wide tables from pushing the layout.
    • 
                  
  • CMS Data Tables: overflow-x-auto, sticky headers, pagination, and all 5 UI states.
    • 
                  
  • CMS Forms: Multi-column responsive grids, inline field errors, and sticky Save / Cancel bar.
    • 
                  
  • Bilingual RTL/LTR: 100% CSS Logical Properties (ms-, me-, start-, end-).
    • 
                

              


              
              

                
BACKEND & DATABASE ARMOR

                
RBAC, Validation, Uploads & Integrity

                
    
                  
  • RBAC Permissions: Locks both UI buttons and API routes (Admin / Editor / User) + anti-IDOR ownership checks.
    • 
                  
  • Server Pagination & Search: Filtering, sorting, and bounded pagination wired to CMS tables.
    • 
                  
  • Field Validation (422): Server validation mapped cleanly to each form input.
    • 
                  
  • Safe File Uploads: MIME/size validation, preview URLs, and old-file cleanup on update/delete.
    • 
                  
  • Database Integrity: Explicit Foreign Keys, Indexes on FKs/filters, Soft Deletes (deleted_at), zero N+1 queries, and atomic transactions.
